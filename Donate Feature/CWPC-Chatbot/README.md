# 🔥 Catastrophic Wildfire Prevention Consortium (CWPC) – AI Donation & Awareness Platform

🚀 Live Website: https://catastrophic-wildfire-prevention-co.vercel.app/

An interactive AI-powered donation and awareness platform built for the **Catastrophic Wildfire Prevention Consortium (CWPC)** at CrowdDoing.  
This project combines wildfire awareness, donation workflows, AI chatbot interaction, innovator mapping, and analytics into a modern responsive web application.

---

# 🌍 Project Overview

The CWPC platform is designed to:

- Promote catastrophic wildfire prevention awareness
- Showcase innovators and climate resilience initiatives
- Encourage donations toward wildfire mitigation efforts
- Provide an engaging AI-powered chatbot experience
- Visualize wildfire innovation ecosystems globally

This project was developed as a modern full-stack style prototype focused on:
- User engagement
- Donation experience optimization
- Interactive UI/UX
- Climate-tech awareness

# 🚀 Local Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SKPVenkataSDeepthi/Catastrophic-Wildfire-Prevention-Consortium-CWPC-at-CrowdDoing.git
```

---

## 2️⃣ Navigate to Project

```bash
cd "Donate Feature/CWPC-Chatbot"
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Run Frontend

```bash
npm run dev
```
